Mac App Store에서 받기Windows용 받기 (무료)

macOS 14 이상 · Windows 10/11 · 같은 네트워크의 맥 1대 + 윈도우 PC 1대

기능

두 컴퓨터를 한 책상처럼.

키보드·마우스 공유

커서와 키 입력이 맥과 윈도우 PC 사이를 넘나듭니다. 연결은 암호화되고 클라우드를 거치지 않습니다.

전환 방식 선택

화면 가장자리로 넘기기, 정한 단축키로만 바꾸기, 둘 다 쓰기 중에서 고릅니다.

클립보드 공유

한쪽에서 복사한 텍스트와 이미지를 다른 쪽에서 붙여 넣습니다.

배치 편집

두 컴퓨터 화면을 실제 비율로 그려 놓고, 끌어서 왼쪽·오른쪽·위·아래 어디에나 붙입니다.

한/영 전환·수정키

두 컴퓨터 모두에서 한글 입력이 됩니다. 맥의 ⌘와 윈도우의 Ctrl도 자동으로 맞춰 줍니다.

메뉴바 도구

잠자기 방지와 외부 모니터 밝기 조절을 메뉴바에서 바로 씁니다.

설치

처음 한 번, 5분이면 됩니다.

  1. 맥: App Store에서 Seamdesk 설치처음 열면 손쉬운 사용 권한을 요청합니다. 키보드·마우스를 넘기려면 꼭 필요하니 시스템 설정에서 Seamdesk를 켜 주세요. 로컬 네트워크 접근을 물으면 허용합니다.
  2. 윈도우: Windows용 Seamdesk 받기Seamdesk-Windows-2.0.0.zip을 받아 압축을 풉니다. Windows 앱은 무료입니다.
  3. 윈도우: Install.cmd 실행“Windows의 PC 보호” 창이 뜨면 추가 정보 → 실행을 누릅니다(아직 코드 서명 전이라 뜨는 안내입니다). 방화벽 규칙을 넣으려고 관리자 승인을 한 번 묻습니다. 개인 네트워크에서만 열립니다. 설치가 끝나면 로그인할 때 자동으로 켜집니다.
  4. 6자리 코드로 짝짓기같은 네트워크에 있으면 두 컴퓨터가 서로를 찾습니다. 한쪽에서 상대를 고르고, 다른 쪽에 뜬 6자리 코드를 넣으면 끝입니다.
  5. 화면 배치 맞추기배치 편집에서 윈도우 화면을 실제 책상 위치에 맞게 끌어다 놓습니다.

FAQ

Windows 앱도 사야 하나요?

아니요. Windows 앱은 무료이고, 이용권은 맥 앱 하나로 관리합니다.

인터넷이 필요한가요?

아니요. 두 컴퓨터가 같은 로컬 네트워크(공유기)에 있으면 됩니다. 연결은 TCP 24810, UDP 24811 포트를 씁니다.

입력 내용이 밖으로 나가나요?

아니요. 키보드·마우스·클립보드 내용은 짝지은 두 컴퓨터 사이에서만 암호화되어 오갑니다. 서버도, 계정도, 분석 도구도 없습니다.

윈도우 잠금 화면이나 관리자 승인 창에서도 되나요?

아니요. Windows 보안 정책상 로그인한 뒤의 화면에서만 입력을 넣을 수 있습니다. 잠금 화면과 관리자 승인 창은 PC의 키보드로 눌러 주세요.

서로 찾지 못해요.

두 컴퓨터가 같은 네트워크에 있는지, 윈도우 네트워크가 “개인”으로 되어 있는지, 설치 때 방화벽 승인을 했는지 확인하세요. 회사·게스트 와이파이는 기기 간 통신을 막기도 합니다.

환불은 어떻게 하나요?

App Store 구매의 환불은 Apple이 처리합니다. reportaproblem.apple.com에서 요청하세요.

Windows 앱을 지우려면?

받은 폴더의 Uninstall.cmd를 실행하면 앱, 자동 시작, 방화벽 규칙을 지웁니다.
