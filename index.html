Features

Two computers, one desk.

Shared keyboard and mouse

The pointer and keystrokes move between your Mac and PC. The connection is encrypted and never goes through the cloud.

Your way to switch

Cross the screen edge, press a hotkey you choose, or use both.

Clipboard sharing

Copy text and images on one computer and paste on the other.

Layout editor

Both screens are drawn to scale. Drag to attach them on any side.

Input sources and modifier keys

Input source switching works on both sides, including Korean. ⌘ and Ctrl are mapped for you.

Menu bar extras

Keep-awake and external display brightness, right from the menu bar.

Setup

About five minutes, once.

  1. Mac: install Seamdesk from the App StoreOn first launch it asks for Accessibility permission, which keyboard and mouse sharing needs; turn Seamdesk on in System Settings. Allow local network access if asked.
  2. PC: download Seamdesk for WindowsDownload Seamdesk-Windows-2.0.0.zip and extract it. The Windows app is free.
  3. PC: run Install.cmdIf “Windows protected your PC” appears, choose More info → Run anyway (the app is not code-signed yet). It asks for administrator approval once to add a firewall rule, for private networks only. Afterwards it starts when you sign in.
  4. Pair with a 6-digit codeOn the same network the two computers find each other. Pick the other computer on one side and enter the 6-digit code shown on the other.
  5. Arrange your screensIn the layout editor, drag the PC screen to where it sits on your desk.

FAQ

Do I need to buy the Windows app too?

No. The Windows app is free; your plan lives in the Mac app.

Does it need the internet?

No. Both computers only need to be on the same local network. It uses TCP port 24810 and UDP port 24811.

Does my input leave my computers?

No. Keyboard, mouse and clipboard data travel encrypted only between your two paired computers. No servers, no accounts, no analytics.

Does it work on the Windows lock screen or UAC prompts?

No. Windows only allows input after you sign in, so use the PC’s own keyboard for the lock screen and UAC prompts.

The computers can’t find each other.

Check that both are on the same network, that the Windows network profile is “Private”, and that you approved the firewall prompt during install. Office and guest Wi-Fi often block device-to-device traffic.

How do I get a refund?

App Store refunds are handled by Apple. Request one at reportaproblem.apple.com.

How do I uninstall the Windows app?

Run Uninstall.cmd from the extracted folder. It removes the app, the sign-in startup entry and the firewall rule.

Privacy Policy

Effective: 2026-11-27

Seamdesk (the Mac app and the Windows app) does not collect personal data.

  • Keyboard, mouse and clipboard data are sent, encrypted, only between the two computers you pair. Nothing is sent to the developer or to third-party servers.
  • Settings and pairing keys are stored only on each computer.
  • There are no analytics, advertising identifiers, trackers or accounts.
  • Purchases and subscriptions are processed by the Apple App Store; the developer never receives payment details (Apple’s privacy policy applies).
