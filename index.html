Seamdesk

Use one keyboard and mouse across your Mac and Windows PC. Move the pointer past the screen edge and keep typing on the other computer.

맥과 윈도우 PC를 키보드·마우스 하나로. 화면 끝으로 커서를 넘기면 다른 컴퓨터에서 그대로 입력합니다.

Features

  • Shared keyboard and mouse between macOS and Windows over your local network (encrypted, no cloud relay)
  • Clipboard sharing: text, images and files up to 10 MB
  • Window snapping shortcuts, keep-awake, and external display brightness control
  • Korean/English input switching works on both sides
